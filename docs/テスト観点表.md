## 今回追加したPlaywrightシナリオ

1. 管理者としてログインする。
2. 社員一覧が表示されることを確認する。
3. 「山田」で検索し、該当社員だけが表示されることを確認する。
4. 社員を登録し、空白が除去されたデータが保存リクエストに渡ることを確認する。
5. 登録した社員が一覧に表示されることを確認する。

**注意:** このシナリオでは、APIをPlaywright内で模擬しています。実データベースへの書き込みや実APIサーバーとの結合は行いません。失敗時のスクリーンショットとトレースはPlaywrightの設定で保存するようにしています。
